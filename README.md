# DaniDunner — сайт за доставка на храна (Варна)

Пълен сайт за онлайн поръчки (Пици, Дюнери, Бургери, Сандвичи, Джобове) с
админ панел и истинска база данни. Обслужва само град Варна (зони по
квартали, всяка със собствена цена за доставка и минимална поръчка).

## Технологии

- **Next.js 16** (App Router, TypeScript, Tailwind CSS 4)
- **SQLite** база данни (файл `data/danidunner.db`) чрез вградения в Node.js
  модул `node:sqlite` — реална, персистентна база, без нужда от отделен
  database сървър **и без нужда от компилатор/Visual Studio Build Tools**
  (нарочно избрахме това вместо `better-sqlite3`, за да върви инсталацията
  гладко на всеки Windows компютър)
- **Stripe** за картово плащане онлайн (по желание — може да смените с
  ePay/Viva Wallet по-късно)
- Админ сесии с JWT (`jose`) + хеширани пароли (`bcryptjs`)

## Първоначално стартиране

Изисква се **Node.js 22.5 или по-нова версия** (тествано с Node 22 и 25).
Проверете версията си с `node -v` — ако е по-стара, изтеглете нова от
https://nodejs.org.

При `npm run dev` / `npm run build` ще видите предупреждение
`ExperimentalWarning: SQLite is an experimental feature` — това е само
информативно съобщение от Node.js, не е грешка, и не пречи на нищо.

```bash
npm install
npm run seed      # създава базата данни с примерно меню, зони, промоции и админ акаунт
npm run dev        # стартира сайта на http://localhost:3000
```

Отворете **http://localhost:3000** за сайта и **http://localhost:3000/admin**
за админ панела.

**Данни за вход в админ панела** (създадени от `npm run seed`):

- Имейл: `admin@danidunner.bg`
- Парола: `DaniDunner2026!`

⚠️ Сменете тази парола възможно най-скоро — най-лесно като зададете
`SEED_ADMIN_EMAIL` и `SEED_ADMIN_PASSWORD` променливи на средата преди
първото стартиране, напр.:

```bash
SEED_ADMIN_EMAIL=you@example.com SEED_ADMIN_PASSWORD="ВашаСилнаПарола1!" npm run seed
```

⚠️ **Внимание:** `npm run seed` изтрива и презарежда менюто, категориите,
зоните, промоциите и настройките (поръчките също се изчистват). Пускайте го
само за първоначално зареждане на демо данни или ако искате пълен reset —
след като добавите свои продукти през админ панела, не го пускайте отново.

## Конфигурация (`.env.local`)

Копирайте `.env.example` в `.env.local` и попълнете:

```
SESSION_SECRET=<дълъг случаен низ>
STRIPE_WEBHOOK_SECRET=<по желание, за Stripe webhook подпис>
```

## Картово плащане онлайн (Stripe)

1. Отворете **Админ панел → Настройки → Разплащане с карта онлайн**.
2. Въведете вашите Stripe **Publishable key** и **Secret key**
   (от https://dashboard.stripe.com/apikeys).
3. Готово — опцията "Картово плащане онлайн сега" на checkout страницата
   ще заработи автоматично.

Ако предпочитате български доставчик като **ePay** или **Viva Wallet**,
логиката за създаване на плащане е изолирана в
`src/app/api/orders/route.ts` (секцията `payment_method === "stripe"`) —
лесно се заменя с техния API, когато имате търговски акаунт при тях.

Наложеният платеж (в брой или с ПОС на куриера) работи веднага, без
никаква допълнителна конфигурация.

## Куриери и GPS проследяване

Системата поддържа собствен екип от куриери (не е маркетплейс с независими
куриери като Glovo/Bolt Food):

- Управителят добавя куриери от **Админ панел → Куриери** (име, телефон,
  парола).
- Куриерът влиза на телефона си на **`/courier/login`** с този телефон и
  парола — вижда мобилен изглед с две листи: "Свободни" поръчки (готови за
  вземане) и "Моите" (взети от него).
- Куриерът сам си взима поръчка от свободните (бутон "Вземи поръчката"),
  маркира "Тръгвам за доставка", после "Доставена". Ако размисли, може да
  освободи поръчката обратно към свободните.
- Докато таб-а на куриера е отворен, браузърът му праща GPS позицията му на
  всеки ~12 секунди (изисква разрешение за локация от телефона/браузъра).
- **Админ панел → Куриери** показва живата позиция на всички активни
  куриери на карта (OpenStreetMap/Leaflet, без нужда от API ключ), плюс
  възможност ръчно да назначите/премахнете куриер на конкретна поръчка от
  **Поръчки**.
- Клиентът вижда позицията на куриера си на живо на страницата за
  проследяване на поръчката (`/order/DD-...`), докато поръчката е в статус
  "На път е" — позицията спира да се показва веднага щом бъде маркирана
  "Доставена".

Демо куриерите от `npm run seed` (сменете паролата им от админ панела или
чрез `SEED_COURIER_PASSWORD` променлива на средата):

- Георги Петров — `0888111111`
- Мартин Иванов — `0888222222`
- Парола (и на двамата по подразбиране): `Kurier2026!`

⚠️ Браузърите разрешават GPS локация само на `localhost` или през **HTTPS**
— на живия сайт (реален домейн) задължително трябва SSL сертификат, иначе
куриерският GPS няма да проработи (повечето хостинги/CDN-и го дават
безплатно, напр. през Let's Encrypt).

## Структура на проекта

```
src/
  app/
    (site)/          — публичен сайт (начало, меню, количка, checkout, поръчка)
    admin/            — админ панел (защитен с логин)
      (dashboard)/    — табло, поръчки, продукти, промоции, зони, настройки
    api/              — API рутове (checkout, промо кодове, зони, admin CRUD)
  components/
    site/             — компоненти на публичния сайт (Header, количка, меню...)
    admin/            — компоненти на админ панела (управление на продукти и др.)
  lib/
    db.ts             — връзка към SQLite базата
    schema.sql         — SQL схема на базата
    repos/            — достъп до данните (продукти, поръчки, зони, промоции...)
    auth.ts            — админ сесии (JWT в httpOnly cookie)
    cart-context.tsx    — количка на клиента (React context + localStorage)
scripts/
  seed.mjs             — примерни данни (меню, зони, промоции, админ акаунт)
```

## Какво може админ панелът

- **Табло** — поръчки днес, приход, активни поръчки, топ продукти
- **Поръчки** — списък, филтър по статус, детайли, смяна на статус
  (Приета → Потвърдена → Приготвя се → На път е → Доставена / Отказана)
- **Продукти и меню** — категории (Пици/Дюнери/Бургери/Сандвичи/Джобове),
  продукти с описание, снимка (URL), цена, размери/варианти (напр. пица
  32см/40см), добавки (extras) с отделни цени, скриване/показване, изтриване
- **Промоции** — промо кодове с % или фиксирана отстъпка, минимална поръчка,
  период на валидност, лимит на използвания, включване/изключване
- **Зони за доставка** — квартали във Варна с индивидуална цена за доставка
  и минимална поръчка за всеки
- **Настройки** — име на сайта, лого, телефон, адрес, работно време,
  безплатна доставка над сума, текст на промо лентата, Stripe ключове
- **Куриери** — добавяне/деактивиране на куриери, живо GPS проследяване на
  карта, назначаване на куриер към конкретна поръчка

## Бележки

- Снимките на продуктите се задават чрез URL адрес в админ панела (напр.
  качени в облак/CDN или директно линкове). Може по-късно да се добави
  качване на файлове, ако е нужно.
- Базата данни е един файл (`data/danidunner.db`) — правете резервно копие
  на тази папка периодично.
- За production хостинг избирайте среда с постоянна файлова система (VPS,
  Docker контейнер и т.н.) — сървърлес хостинги като Vercel изтриват
  локални файлове между заявките, което ще счупи SQLite базата.
